# 随机抽名字（老虎机式抽奖）

一个纯前端的随机抽名字工具：开始后在屏幕上快速滚动名单，到指定时刻（或滚动指定时长后）**逐渐减速**，最终定格在抽中的名字上。

## 特性

- **现场开奖体验**：全屏大字体、减速动画（快 → 慢 → 逐个停顿 → 定格）、滚动实时倒计时（末段变色）、揭晓高亮 + 合成音效（无需音频文件）
- **公平性**：滚动只是视觉效果，**结果在停止瞬间才用 `crypto.getRandomValues()`（密码学级随机源）抽取**，拒绝采样保证均匀分布
- **双模式计时**：
  - 滚动时长模式：开始后滚动 N 秒
  - 指定时刻模式：滚动到某个时刻（如 10:30 准时开奖）
  - 启动对表后用 `performance.now()` 单调时钟计时，不受系统改时间影响
- **名单管理**：CSV 存储，页面内增删、批量粘贴、导入/导出 csv（兼容旧 txt）、localStorage 持久化
- **主持-观众分享**：主持人在「指定时刻」模式下点「分享」，生成带种子的观众链接 + 二维码；观众打开即自动观看滚动，到点与主持人端定格**同一个结果**；开奖后进入的观众会看到 3 秒补播再揭晓。结果由 seed + 名单确定性算出，链接自包含（名单嵌在 URL fragment），无需任何后端
- **防误触**：滚动中和揭晓后空格无效，必须 Esc 重置才能再次抽取；观看模式下观众无开始/重置权限

## 使用

需要以 HTTP 服务方式打开（双击 file:// 打开也能用，但会使用内置兜底名单而非 `data/names.csv`）：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后浏览器打开 `http://localhost:8000`。

### 快捷键

| 按键 | 作用 |
|---|---|
| 空格 | 开始抽取（待机状态下） |
| Esc | 重置回待机 / 关闭弹窗 |
| F | 全屏切换 |

### URL 参数

- `?duration=30` —— 滚动 30 秒
- `?at=10:30` —— 今天 10:30 开奖
- `?at=2026-09-15T10:30` —— 指定日期时刻开奖

也可以在页面右上角「设置」里配置，配置会保存。

### 名单（CSV 格式）

默认名单在 `data/names.csv`：首行为表头 `name`，之后一行一个名字，`#` 开头为注释。Excel 可直接编辑（另存为 CSV UTF-8）。页面内的「名单」抽屉支持增删、批量粘贴导入、导出 csv（带 BOM，Excel 打开不乱码）；修改保存在浏览器 localStorage，点「恢复默认」可还原。

## 部署

纯静态站点，任何静态服务器都能跑。详细步骤（域名解析 + Caddy/Nginx + HTTPS）见 [deploy/README.md](deploy/README.md)；也可直接开启 GitHub Pages。

## 文件结构

```
├── index.html        # 入口页面
├── css/style.css     # 全屏舞台、滚动抖动、倒计时、揭晓高亮动画
├── js/
│   ├── main.js       # 状态机（待机→滚动→揭晓）、倒计时、快捷键、音效、UI 绑定
│   ├── timer.js      # 双模式计时（单调时钟）
│   ├── roller.js     # 滚动渲染 + 减速曲线
│   ├── picker.js     # 抽奖核心：停止瞬间 crypto 级随机抽取
│   └── namelist.js   # 名单管理（CSV 解析/导出）与抽屉 UI
├── data/names.csv    # 默认名单（CSV）
└── deploy/           # 云服务器部署指南与配置示例
```
